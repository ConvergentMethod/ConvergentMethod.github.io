How to Update or Add Employees Team Directory

The add-in uses a centralized team directory inside launchevent.js. Here is how you manage employees:

Method A: Using this Web Studio (Easiest)

  1. To update existing staff (e.g. Amanda): Click the Amanda Stemmans tab, update her phone/title/email, and the website auto-saves it.
  2. To add a new employee: Click the Custom Employee tab, enter the new hire's name, title, email, and direct phone line.
  3. Click Save / Download launchevent.js and overwrite outlook-addin/launchevent.js in this folder.
  4. Run git push so the updated directory goes live for all users!

Method B: Directly in launchevent.js (In Code)

Open outlook-addin/launchevent.js and add or edit entries in TEAM_DIRECTORY:

"newemployee@convergentmethod.com": {
  name: "Jane Doe, P.E.",
  title: "Senior Project Manager",
  email: "JaneD@convergentmethod.com",
  phone: "(281) 979-1336",
  phoneLink: "+12819791336"
}

Note: Any corporate employee not explicitly listed in the dictionary automatically gets an official branded signature pulling their name and email straight from their Microsoft 365 profile!

Initial Setup: Deploy Across Microsoft 365 Organization

If you haven't deployed the add-in to your tenant yet, follow these one-time steps in the Microsoft 365 Admin Center:

  1. Sign in to the Microsoft 365 admin center as a Global or Exchange Administrator.
  2. In the left navigation menu, expand Settings → click on Integrated apps.
  3. Click Upload custom apps at the top of the page.
  4. Under App type, choose Office Add-in.
  5. Select Provide link to manifest file and paste your hosted manifest URL:
    (Or select Upload manifest file (.xml) from device and upload manifest.xml).
  6. Click Next. On the Assign users page, choose Entire organization.
  7. Review permissions (ReadWriteItem) and click Finish deployment.

Deployment completes organization-wide in the background. Users do not need to download or configure anything.
